# Precision UI 적용 설계

## 목표와 승인
2026-10-25 사용자가 승인한 방식으로 현재 ModuDock-Go의 모든 기존 UI를 Precision 스타일로 통일한다. 사용하지 않는 전체 컴포넌트는 설치하지 않으며, 이후 공식 레지스트리에서 개별 추가할 수 있게 한다.

## 접근 방식
- 전체 `all.json -o` 설치는 미사용 AI/차트 컴포넌트와 의존성을 늘리고 기존 UI 계약을 덮어쓰므로 제외한다.
- CSS 색상만 교체하면 버튼의 그림자·포커스·표·탭이 불일치하므로 제외한다.
- 공식 토큰과 실제 사용하는 컴포넌트의 스타일을 기존 React 19/Radix 공통 컴포넌트에 통합한다. 이 방식이 사용자 승인안이다.

## 범위
로그인/MFA/복구 코드, 사이드바와 모바일 서랍, 대시보드/상태/바로가기, 사용자/API 토큰/메뉴 설정, 플러그인 설치·스키마 폼·표·탭, 작업 이력/스케줄/로그 화면을 포함한다. Go API, DB, 인증과 플러그인 동작은 변경하지 않는다.

## 시각 규칙
공식 현재 레지스트리의 밝은 테마를 사용한다. primary `oklch(0.575 0.176 268)`, foreground `oklch(0.21 0.006 271)`, radius `0.375rem`, 얇은 경계와 다층 그림자, 조밀한 간격을 적용한다. Lucide와 한글 시스템 폰트 대체 경로는 유지한다. 상태 색은 성공/경고/실패 의미를 유지하면서 토큰화한다. QR은 흰 배경과 여백을 보존한다.

## 통합 제약
기존 컴포넌트 export/props/data-slot과 Radix 키보드·포커스 동작을 보존한다. 네이티브 select/checkbox는 폼 제출 계약을 바꾸지 않고 동일 스타일을 적용한다. 불필요한 motion 패키지나 원격 폰트/MCP를 런타임에 추가하지 않는다. CSS 전환과 reduced-motion을 사용한다. MIT 고지를 빌드의 third-party notices에 포함한다.

## 검증
기존 프론트 테스트, 실제 브라우저에서 데스크톱/모바일 모든 메뉴와 로그인·MFA 화면, 포커스·탭·서랍·표 스크롤·긴 내용, TypeScript/Vite 빌드, Go 임베디드 배포 빌드/스모크를 확인한다. NAS 업로드와 GitHub push는 범위 밖이다.

# 계정 보안 보강 계획

작성일은 2026-10-25이며, 대상은 기존 Python 프로젝트가 아닌 ModuDock-Go이다.

## 목표

계정별 TOTP와 QR 등록, 일회용 복구 코드, 사용자 확인이 필수인 Passkey 로그인을 추가한다. Go·SQLite·내장 React UI·단일 컨테이너와 네이티브 배포를 유지한다.

## 순서와 확인 기준

1. 현재 인증 구조를 확인하고 보안 설계 문서를 독립 검토한다. 사용자 승인 여부를 기록한다.
2. 승인 후 테스트 중심 상세 구현 계획을 작성한다. DB 마이그레이션, 키 보관, 인증 대기 상태와 세션 발급 경계를 정의한다.
3. 서버 기능을 구현한다. 미완료 인증, 코드 재사용, 동시 요청, 만료, 계정 변경 및 API 토큰 우회를 테스트한다.
4. 로그인·계정 보안 UI를 연결한다. QR·수동 키·6자리 코드, 복구 코드, Passkey 등록·로그인·삭제를 확인한다.
5. 회귀 테스트, 빌드, Docker/네이티브 스모크와 브라우저 검증을 수행한다. 수행하지 못한 실기기 확인은 표시한다.
6. 설치·백업·복구·API 문서를 갱신하고 논리적 변경별 로컬 커밋을 만든다. NAS 업로드와 원격 푸시는 하지 않는다.
